# PC Agent for Windows

Official PC Agent builds. Download `PC-Agent.exe`, run it on your Windows computer, and connect the computer through your PC Agent account.

Официальные сборки PC Agent. Скачайте `PC-Agent.exe`, запустите на Windows и подключите компьютер через личный кабинет PC Agent.

- [Download for Windows / Скачать для Windows](https://github.com/Paketik2010/pc-agent-releases/releases/latest/download/PC-Agent.exe)
- [Releases and checksums / Релизы и контрольные суммы](https://github.com/Paketik2010/pc-agent-releases/releases/latest)
- [Website / Сайт](https://pc-agent-chatgpt.web.app/)

PC Agent connects ChatGPT to local files, programs, background processes, browsers and desktop controls through MCP. Long tasks can expose progress and output for review. Available actions depend on the permissions configured in PC Agent and the capabilities of your chat client.

PC Agent даёт ChatGPT доступ к локальным файлам, программам, фоновым процессам, браузерам и управлению рабочим столом через MCP. Долгие задачи могут передавать состояние и вывод для проверки. Доступные действия зависят от разрешений PC Agent и возможностей вашего чата.
